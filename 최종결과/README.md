# 📂 폴더 안내

이 폴더 안에는 우리 프로젝트의 모든 결과물이 다음과 같이 정리되어 있습니다.

```
최종결과/
├── 📘 종합보고서.md         ← 비전공자용 종합 보고서 (먼저 이걸 읽으세요)
├── 📊 그래프/                ← 분석 결과 시각화 6장
├── 📁 데이터/                ← 단계별 데이터셋 (CSV 4종)
├── 💻 코드/                  ← 분석에 사용한 Python 스크립트 7개
└── 📋 기술보고서/            ← 각 단계별 상세 기술 보고서 (전공자용)
```

## 🔰 처음 보시는 분은 이렇게 읽으세요

1. **`종합보고서.md`** — 5~10분이면 전체 흐름과 결과를 이해할 수 있습니다.
2. **`그래프/` 폴더** — 결과를 그림으로 확인합니다.
3. (선택) **`기술보고서/` 폴더** — 단계별 상세 분석이 궁금하면.
