# 초기 프로젝트 목표 달성 평가 (Notion 목표 기반)

> 결론: **목적 ①②는 거의 완성, 목적 ③은 절반, 목적 ④는 동서 격차 부분이 미구현.**
> 완성까지 필요한 핵심 작업 = (a) 부산 시·군·구 단위 데이터, (b) Lag/누적효과 분석, (c) 서울·경기 SC 분석, (d) 결과 대시보드.

**달성도 : 60%**

| 항목 | 구현 상태 | 비고 |

### 목적 ③ 부산에 유사 정책 도입 시 미달률 감소 효과 예측 시뮬레이션
**달성도 : 50%**

| 항목 | 구현 상태 | 한계 |
|---|---|---|
| 부산 SC 합성 시계열 | ✅ | 합성 부산 vs 실제 부산 격차 산출 |
| 정책강도 회귀 기반 외삽 | ⚠️ | β ≈ 0이라 시나리오가 무의미 |
| **서울·경기 정책효과를 부산에 이식하는 시뮬레이션** | ❌ | 미구현 |
| **Lag/누적효과 시뮬레이션** | ❌ | 미구현 (지속성 평가용) |
| **부산학력개발원 이전·이후 비교** | ❌ | 2022년 설립을 이벤트 시점으로 사용 가능 |

→ 현재 모형은 "부산 대 합성부산"의 격차만 보고. **"서울/경기 수준으로 끌어올리면 부산이 어떻게 될지"** 시뮬레이션이 핵심인데 미구현.
→ 보강 방법:
1. 서울·경기의 정책 강도 β 추정 → 부산에 적용한 counterfactual.
2. Lag(t-1, t-2) 회귀로 지연효과 반영한 외삽.
3. 부산학력개발원 설립(2022) 전/후 위험도 추세 비교.

## 3. 완성을 위한 작업 로드맵 (우선순위)

### 🔴 1순위 — 목적 ④ 완성 (가장 큰 결손)
- **부산 16개 구·군 패널 구축**
  - 학생수, 학업중단률, 다문화 학생 수, 학급당 학생수 (KOSIS·학교알리미)
  - 동/서 구분 (예: 강서/사하/사상/북구/금정 = 서부, 해운대/수영/남구/동래 = 동부)
  - 자치구별 학력향상사업비 (부산교육청 교육지원청 예산서)
- **동서 격차 분석**: 두 그룹의 위험도 평균·격차 시계열 + DiD

### 🟠 2순위 — 목적 ② 완성
- **서울·경기 정책효과 분석**: 부산과 동일 방법(SC + DiD + 패널회귀) 일괄 실행
- 서울·경기·부산 3개 사례 비교표 작성

### 🟠 2순위 — 목적 ③ 강화
- **Lag 변수**: 학력향상지원 t-1, t-2를 패널회귀에 추가 → 지연효과 추정
- **누적 5년 지원 강도**: 위험도 추세와의 회귀
- **부산학력개발원 설립(2022) Event Study**: 위험도 추세의 구조변화 검정
- **서울 효과 이식 시뮬레이션**: 서울의 β를 부산에 적용한 counterfactual

### 🟡 3순위 — 추가 자료 확보 시 보완
- KICE 지역등급(대도시/중소도시/읍면) 실측 미달률로 위험도 지수 외부 타당성 검증
- 부산학력개발원 사업 raw 데이터 (프로그램별 수혜 학생 수, 결과)
- 두드림학교 지정 학교 목록 (학교 단위 인과 식별)
- 수능 상위등급 비율 시도별 시계열

### 🟢 4순위 — 발표/제출용 자료화
- **위험도 모니터링 대시보드** (Streamlit/Dash, 시도별·연도별 인터랙티브)
- **정책 시뮬레이터** (지원액 슬라이더 → 예상 위험도 변화)
- **최종 보고서** PDF/HWP
